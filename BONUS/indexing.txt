
1. What is a database index and what problem does it solve? Explain in your own words.:

An index is a data structure that orders data in a table to help find rows faster. Before adding an index, when we search in a table we need to go through all the data in the table. After adding an index, it orders the data by alphabet or number, so we can find the row directly without checking every row.
